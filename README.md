# 가열 곡선 비교 — 순물질 vs 혼합물

중학교 2학년 과학 · 물질의 특성 단원 교육용 인터랙티브 시뮬레이션.
성취기준 **[9과08-02]** 물질의 특성을 근거로 순물질과 혼합물 분류하기.

## 무엇을 보여주나

물과 소금물을 똑같이 가열할 때의 가열 곡선을 나란히 비교한다.

- **물(순물질)** — 끓는 동안 100℃에서 온도가 일정.
- **소금물(혼합물)** — 끓는점이 더 높고, 물이 증발해 농도가 진해질수록 온도가 계속 상승.

겉모습이 아니라 "끓는점이 일정한가"가 순물질과 혼합물을 가르는 근거임을 시각화한다.

## 물리 모델

끓는점 오름 ΔT_b = i·K_b·m (NaCl: i=2, K_b=0.512 ℃·kg/mol) 기반.
끓는 동안 증발로 인한 농도 변화와 포화(약 26%)를 반영. 농도 변화 폭은 학습용으로 보기 좋게 조정.
